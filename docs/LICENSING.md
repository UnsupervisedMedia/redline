Redline's own code is **Apache-2.0** (`LICENSE`, `NOTICE`).

## Rust dependencies
`THIRD_PARTY_LICENSES.md` lists every crate in `Cargo.lock` with its SPDX license.
`cargo deny check` (config: `deny.toml`) runs in CI and fails on any license outside the allow-list.
There is no GPL or AGPL code in the dependency graph. Notes on the non-permissive entries:

| Crate(s) | License | Note |
|---|---|---|
| `resvg`, `usvg`, `cssparser`, `selectors`, … | MPL-2.0 | File-level copyleft. Used unmodified as libraries; Apache-2.0 distribution is compatible. |
| `r-efi` | MIT OR Apache-2.0 OR LGPL-2.1-or-later | Triple-licensed; we use it under MIT/Apache-2.0. |
| `epaint_default_fonts` | OFL-1.1 / UFL-1.0 and others | egui's built-in fonts (Ubuntu-Light, Hack, emoji icon fonts). |

Optional features add dependencies not exercised by default builds: `native-inpaint` (ONNX Runtime via `ort`, loaded dynamically, MIT),
`native-generative` (candle, Apache-2.0/MIT, requires CUDA toolchain), `pdf` (PDFium, BSD-3-Clause / Apache-2.0), `lama-webview` (GTK3 + WebKitGTK, LGPL, linked dynamically).
